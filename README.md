# 🦷 Booking Appointments

A modern appointment booking and management system built with Laravel, designed to streamline scheduling and patient appointment workflows.

## 🚀 Overview

Booking Appointments is a web application that helps manage appointments efficiently through a simple and user-friendly interface. The project follows Laravel best practices and focuses on scalability, maintainability, and clean architecture.

This project is part of my Laravel learning journey, where I focus on implementing real-world features and applying software engineering best practices.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Daniaprodash/Booking-appointments.git

```

Navigate to the project directory:

```bash
cd Booking-appointments

```

Install PHP dependencies:

```bash
composer install

```

Install frontend dependencies:

```bash
npm install

```

Create the environment file:

```bash
cp .env.example .env

```

Generate the application key:

```bash
php artisan key:generate

```

Configure your database settings inside the `.env` file.

Run database migrations:

```bash
php artisan migrate

```

Create a symbolic link for storage:

```bash
php artisan storage:link

```

Start the development server:

```bash
php artisan serve

```

Run Vite development server:

```bash
npm run dev

```
